How it worksCó thể huỷ

1. Chọn payload DuckyScript trong LittleFS hoặc SD (ví dụ /payload.txt). 2. Bật Enable. 3. Cắm USB vào host — firmware đợi delayMs sau khi tud_mounted(), nếu bật xác nhận thì hiện countdown confirmMs (mặc định 3000ms), bấm nút để hủy, không thì chạy key_input(). Lưu persistent trong bruce.conf → badUsbAutoRun. Trigger: Enumeration (mặc định) hoặc Delayed thêm 2s. VBUS chưa hỗ trợ. Chạy lặp chỉ khi tắt Run once; mỗi lần đều kiểm tra kết nối và cửa sổ xác nhận.

Chọn “Dùng làm payload” tại file cần dùng. Chưa chạy hoặc lưu tự động.
