## 1. Mục tiêu & phi mục tiêu

**Mục tiêu**
1. Việc lặp là công dân hạng nhất: tạo–sửa–dừng–bỏ qua–cuối chuỗi, mọi thao tác 1 chạm và **Ctrl+Z được**.
2. Quy tắc đầy đủ: tần suất **Ngày/Tuần/Tháng/Năm**, **khoảng lặp tùy ý** (`mỗi N ngày/tuần/tháng/năm`), **chọn thứ trong tuần** (tuần), **ngày trong tháng** (gồm "ngày cuối cùng"), **kết thúc**: không bao giờ / **đến ngày** / **sau N lần hoàn thành**.
3. **Ghost calendar** trong modal tạo/sửa: thấy trước mọi ngày việc xuất hiện; **chạm vào ngày = đặt hạn lặp**; có các chip đặt nhanh (+1th / +3th / +6th / Cuối năm).
4. **Câu tóm tắt ngôn ngữ tự nhiên tiếng Việt**, cập nhật trực tiếp: *"Mỗi 2 tuần vào Thứ Hai & Thứ Năm · đến 31/12/2026 (~19 lần nữa)"*.
5. **Tương thích ngược tuyệt đối** với data v2.8.0 — file tự nâng cấp, không mất gì, không cần user làm gì; downgrade build cũ **không** nhân bản loạn.
6. Nhất quán triết lý app: **layer-1** (không AI), **ADHD-safe** (không quota/streak, copy dịu), **undo mọi thứ**, tiếng Việt, **một nguồn sự thật cho thuật toán** (Rust; JS không mô phỏng lại).

**Phi mục tiêu (v1)**
- Không sync đám mây, không xuất RRULE/iCalendar (để sau nếu cần).
- Không xử lý ngoại lệ từng instance ("dời lần này, giữ nguyên các lần sau").
- Không nhắc nhở theo giờ (app vốn chỉ theo NGÀY).
- Không biểu diễn by_day/month_day qua quick-add (vẫn chỉ trong modal) — phase 2 (§12).
- Không tạo "Xoá cả chuỗi (kèm lịch sử)" — bulk trong Đã hoàn thành đã đủ v1 (§6.4).

## 4. Quyết định kiến trúc

### 4.1 Giữ "clone khi hoàn thành"; không ảo hóa occurrence (bảng trade-off)

| Tiêu chí | Clone-on-complete (CHỌN) | Virtual occurrence |
|---|---|---|
| Undo/Redo | `store.clone()` → hoàn tác *cả series lẫn instance vừa tạo*, miễn phí | Mọi consumer (list, counts, stats, focus, drag, export…) phải hiểu phần tử ảo; undo phức tạp gấp nhiều lần |
| Backup/sync JSON | Không đổi | Đổi sâu |
| Sửa rule giữa chuỗi | Rule nằm trên instance đang sống → lần clone kế tiếp dùng rule mới ✓ tự nhiên | Phải version theo timeline |
| Effort | Thấp, rủi ro thấp | Viết lại ~nửa app |

**Bù trừ (điểm yếu đã biết → cách xử bắt buộc):**
- *"Đến ngày nào"* → enforce **ngay lúc hoàn thành** (không clone nếu vượt `until`/hết `after`) **và** khi nạp/lưu/đổi rule: instance chưa xong có rule **không còn occurrence nào trong tương lai** → tự thành việc thường (rule → `None`) + flash 1 lần.
- *Cần thấy trước* → ghost calendar + "≈ N lần nữa" (§6.2).
- *Cần thoát lịch tạm* → action **Bỏ qua lần này** (§4.5).

### 4.2 Rule model (serde-tương thích ngược, không bump `version`)

```rust
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct RecurrenceRule {
    pub freq: Freq,                 // Day | Week | Month | Year
    #[serde(default = "one")]
    pub interval: u32,              // 1..=99 (kẹp)
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub by_day: Option<u8>,         // Week: bitmask Mon..Sun (bit0=T2 … bit6=CN)
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub month_day: Option<i8>,      // Month: 1..=31, -1 = ngày cuối tháng
    #[serde(default)]
    pub ends: EndSpec,              // Never | Until{date} | After{total, done}
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum Freq { Day, Week, Month, Year }

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum EndSpec {
    Never,
    Until { date: NaiveDate },   // NGÀY CUỐI CÙNG việc có thể xuất hiện
    After { total: u32, done: u32 },
}
```

**Chiến lược serde + migration (không đụng `current_version() = 1`):**
- Task giữ **cả hai**: `repeat: Repeat` (legacy, `#[serde(default)]`, **shadow**) + `recurrence: Option<RecurrenceRule>` (chính).
- `Store::sanitize()` (mỗi lần nạp):
  1. `recurrence == None && repeat != None` → nâng cấp:
     `Daily→{Day,1}` · `Weekdays→{Day,1,by_day:0b0011111}` · `Weekly→{Week,1}` · `Monthly→{Month,1}`.
  2. Ghi ngược `repeat = shadow(recurrence)`: rule "đơn" → đúng enum cũ (Daily/Weekdays/Weekly/Monthly); rule **custom** (interval>1, mask khác, until/after…) → `None`. Build cũ mở file này thấy "Không lặp" nhưng **tuyệt đối không** nhân bản — **lùi an toàn**.
  3. Rule hết hạn còn trên **việc chưa xong** (predicate duy nhất: `next_after(rule, task.due) == None` — §4.6) → `recurrence = None` (việc thành thường, giữ due quá khứ → vào Hôm nay).
- Build mới **chỉ** dùng `recurrence` cho logic; `Repeat` còn mỗi vai trò shadow.

### 4.3 Thuật toán occurrence — **đúng 1 nơi (Rust)**

> ⚠️ JS **KHÔNG** mô phỏng lại. Detail hint lẫn ghost calendar đều gọi backend (`invoke("preview_occurrences")` / `next_occurrence`), debounce 120ms. Trước đây hint từng có `nextRepeatDate()` trong JS — **xoá bỏ**, tránh drift preview ↔ thực thi (xấu hổ nhất là nói T5 mà lịch tô T6).

```
fn occurrences(rule, from, limit) -> Vec<NaiveDate>   // sinh tuần tự, clamp limit=200

fn next_after(rule, from) -> Option<NaiveDate>:
    match rule.ends:
        After{total, done} if done >= total  => None
        _ => {}
    let base = match freq:
        Day   => from + interval ngày
        Week  =>
            if let Some(mask):
                # anchor = due lúc tạo rule; nếu due KHÔNG nằm trong mask,
                # instance hiện tại vẫn diễn ra, occurrence ĐẦU TIÊN theo mask từ sau due
                let aw = week_start(from)                       # Thứ Hai
                tìm ngày d > from nhỏ nhất:
                    mask(d.weekday()) == 1
                    && weeks_between(aw, week_start(d)) % interval == 0
            else: from + 7*interval ngày
        Month =>
            let anchor = rule.month_day.unwrap_or(from.day())     # 1..=31 hoặc -1
            let m = from.month + interval (calendar arithmetic trên FIELD THÁNG, không cộng ngày)
            day = nếu anchor == -1 { last_day(m) } else { min(anchor, last_day(m)) }
            date(m, day)
            # KHÔNG dùng checked_add_months(due) — sẽ trôi ngày (31/1→28/2→28/3…). Xem §13.
        Year  => from + interval năm, clamp 29/2 → 28/2
    match rule.ends:
        Until{date} if base > date => None
        _ => Some(base)

fn rule_exhausted(rule, ref_date) -> bool:
    next_after(rule, ref_date) == None || (task due quá until và đã xong mọi occurrence — như nhau)
```

**Bất biến & kiểm thử bắt buộc**
- `until` là **ngày cuối cùng việc xuất hiện** (base == until vẫn OK; sau 1 ngày = hết).
- `after.total` = **số lần bấm Hoàn thành** cần có (sau khi đặt rule) — KHÔNG cộng ngược lịch sử đã hoàn thành (không có series marker; giới hạn đã biết, chấp nhận).
- `after.done` đếm trên **clone** (instance sắp tới mang `done+1`); instance vừa hoàn thành giữ `done` cũ để lịch sử nhất quán. Undo = clone restore → cả hai trở về nguyên trạng ✓.
- **Kiểm hết-chuỗi ở thời điểm hoàn thành dùng `done + 1 >= total`** (không spawn khi đã đủ): place rule After{10} → đúng 10 lần Hoàn thành là dừng. `next_after` thuần (dùng cho skip/sanitize/preview) dùng `done >= total`. Hai predicate, một chỗ (Rust), có unit test.
- **`month_day` đóng băng ngay khi có thể** (insert/sanitize/set_task_recurrence: `None` → ngày hạn (hoặc hôm nay)) — thiếu bước này thì clamp 31→28/2 làm mất anchor, chuỗi trôi (31/1 → 28/2 → **28/3**) — bắt buộc theo §13.
- `preview_occurrences` đếm budget After = `total - done` (gồm lần hiện tại) cho "≈ N lần nữa"; phần generate clone budget = `total - done - 1`.
- by_day rỗng → chặn ở UI (không lưu).
- interval 0 → kẹp 1; >99 → kẹp 99.
- Month không trôi ngày (test chuỗi 31/1 → 28/2 → 31/3 với anchor=31; và -1 → 31/1 → 28/2(29) → 31/3).
- Year 29/2 → 28/2 năm thường → 29/2 năm nhuận kế tiếp.
- Week interval=2 mask{T2,T5}: liệt kê 12 tuần kiểm tra.

### 4.4 Luồng hoàn thành — mới

```
Act::Toggle(id):
    push_undo
    task.completed_at = now
    if let Some(rule) = &task.recurrence {
        match next_after(rule, task.due.unwrap_or(today)) {  // dừng nếu After đủ, hoặc không còn occurrence nào ≥ hôm nay (until trôi qua)
            None => flash("✓ Xong — chuỗi lặp đã kết thúc" hoặc "✓ Xong — đủ N lần như đã hẹn"),
            Some(next) => {
                let mut rule2 = rule.clone();
                if After{total,done} = &mut rule2.ends { done += 1; }   // đếm trên CLONE
                spawn clone { due: next, recurrence: rule2, starred:false,
                              subtasks done=false, completed_at=None }
                flash("✓ Xong — lần tiếp theo: Thứ Hai, dd/mm/yyyy")
            }
        }
    }
```

### 4.5 Bỏ qua lần này — `Act::SkipOccurrence { id }` (MỚI)

1. `push_undo`
2. `base = max(task.due, today)` — bảo đảm **luôn tiến về phía trước** kể cả với instance quá hạn (bỏ qua "hôm nay" khi due<t oday không bao giờ kết quả ở hôm nay/quay lui).
3. `next = next_after(rule, base)`; nếu `None` → nút **bỏ qua bị vô hiệu hoá** (tooltip "Sắp hết lặp — không còn lần nào để bỏ qua").
4. set `task.due = next`; KHÔNG đụng `completed_at`, KHÔNG tăng `after.done`.
5. flash `Đã bỏ qua — chuyển sang <Thứ>, dd/mm/yyyy` + undo.

Dùng khi: nghỉ ốm, đi công tác, "hôm nay không tập".

### 4.6 Khi nạp/lưu/đổi-rule (sanitize) — luật đồng nhất

```
for task in tasks where recurrence != None && !completed:
    // một predicate duy nhất cho cả 2 loại kết thúc (tính từ max(due, hôm nay)
    // để chuỗi until đã trôi hết KHÔNG sinh việc ma, dù due còn nằm trước until):
    if next_after(rule, max(task.due, today)) == None:
        task.recurrence = None   // thành việc thường
        note_flash_once("Đã chuyển “<title>” thành việc thường (lặp đã hết hạn)")
```
Gọi tại: load (`sanitize`), và ngay sau khi **Lưu** trong modal (cùng predicate) — một đường duy nhất, không hai bản sao.

**Ghost calendar — chi tiết kỹ thuật**
- Lưới 42 ô; tuần bắt đầu **Thứ Hai** (khớp VI_DOW); cell ≥ 38px, ≥ 44px ở ADHD mode.
- **Trạng thái**: quá khứ mờ (bất động) · hôm nay viền accent · **ngày việc xuất hiện** nền tím mờ + chấm đặc · until = ô tím đặc chữ trắng (+ mọi ô sau dim).
- **Chạm/click ô** trong chế độ "Đến ngày" → `until = ô đó`, re-render + summary cập nhật. Ngoài chế độ "Đến ngày" → chỉ xem (**không** side-effect ẩn).
- Tooltip ô: `Sẽ xuất hiện vào Thứ Năm, 27/11`.
- Dòng dưới: "≈ N lần nữa" (từ hôm nay → until; vô hạn → đếm tối đa 200, hiển thị "200+").
- Header `‹` `›`: không lùi trước tháng hiện tại; không vượt until (nếu có) hoặc +24 tháng.
- Cảnh báo tinh tế khi tắt chính thứ đang chứa `due` của lần hiện tại: *"Lần hiện tại (Thứ Tư) không nằm trong lịch lặp — chuỗi bắt đầu từ lần sau."*
- **Empty-state**: rule không có occurrence nào tới trong 12 tháng (mask lệch) → hint cảnh báo dịu.
- Animation chấm fade stagger 6ms; reduce-motion: tắt hết.
- **Dữ liệu chấm lấy 100% từ backend** `preview_occurrences` (Rust, ≤200 điểm, debounce 120ms khi user chỉnh) — preview không bao giờ lệch với hành vi thật.

**Validation (inline, không popup) & lỗi**
- `interval` 0 → kẹp 1 + viền đỏ; `>99` → kẹp 99.
- by_day rỗng → viền đỏ + "Chọn ít nhất 1 thứ trong tuần"; **Lưu bị vô hiệu hoá**.
- until < hôm nay → "Ngày kết thúc phải ở tương lai"; Lưu disabled.
- after.total < 1 → kẹp 1.
- Lỗi nào cũng **block lưu** — không bao giờ có rule hỏng trong file.

### 6.3 Quick-add (D4 — làm luôn trong v2.9.0)

## 13. Phụ lục — ca tràn tháng (vì sao không dùng checked_add_months)
- checked_add_months(31/1, 1) → 28/2 (clamp). checked_add_months(28/2, 1) → 28/3 ⇒ **trôi ngày**.

- Chuỗi test bắt buộc: anchor=31: 31/1 → 28/2(2026) → 31/3 → 30/4 …; anchor=-1: 31/1 → 28/2 → 31/3; anchor=30 tháng 2 → 28/2; anchor=29 năm nhuận → 28/2 năm thường → 29/2 năm nhuận kế.
