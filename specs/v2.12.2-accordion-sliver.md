# Spec v2.12.2 — Vá “nhóm accordion Cài đặt thu gọn vẫn hở khe nhỏ”

> Báo cáo của chủ dự án (kèm ảnh chụp nhóm **“Khay hệ thống & phím tắt”** ở trạng thái thu gọn trên v2.12.1): dưới tiêu đề nhóm vẫn còn lộ **một khe ~20px** của dòng đầu tiên (tiêu đề dòng “Khi đóng cửa sổ chính” + mép nút segmented `Hỏi / Thu vào khay / Thoát`), thay vì đóng khít.

## Phạm vi

Toàn bộ nút accordion **Cài đặt → mọi nhóm** (Giao diện, Khay hệ thống & phím tắt, Tập trung, Thông báo, Quản lý tác vụ, Dữ liệu, Lưu trữ, Khác) — chúng dùng chung `.settings-group-body` / `.settings-group-inner`.

## Phân tích nguyên nhân (gốc)

CSS (v2.11.0 — C.3, giữ nguyên tới v2.12.1):

```css
.settings-group-body  { display:grid; grid-template-rows: 1fr; transition: grid-template-rows .22s ease; }
.settings-group.is-collapsed .settings-group-body { grid-template-rows: 0fr; }
.settings-group-inner { overflow: hidden; min-height: 0; padding: 6px 18px 12px; border-top: 1px solid var(--stroke); }
```

- `grid-template-rows: 0fr` tương đương `minmax(auto, 0fr)` — **min `auto`** của track là phần đóng góp tối thiểu của item (`.settings-group-inner`).
- `min-height: 0` cho phép item shrink về 0 cho phần **nội dung** (scroll container → contribution nội dung ≈ 0), **nhưng** document có `* { box-sizing: border-box }`: chiều cao border-box của một hộp **không thể nhỏ hơn** `padding-top + padding-bottom + border-width`.
- Floor thực tế của inner khi thu gọn = `6 + 12 + 1 = 19px` ⇒ track không bao giờ xuống dưới ~19px ⇒ **còn hở khe ~19–20px** (thấy phần trên của dòng đầu). Phù hợp hoàn toàn với ảnh chụp (khe ≈ 20px; nút segmented của dòng 1 hé đúng mép trên).
- Vì vậy mọi nhóm đều dính lỗi; không liên quan tới JS toggle lớp `is-collapsed` (class, `aria-expanded`, badge đều đúng).

## Bản vá (v2.12.2)

`src-ui/styles/settings.css`:

```css
.settings-group-inner {
  overflow: hidden; min-height: 0;
  border-top: 1px solid var(--stroke);
  padding: 6px 18px 12px;
  transition: padding .22s ease, border-width .22s ease, border-color .22s ease;
}
.settings-group.is-collapsed .settings-group-inner {
  border-top-color: transparent;
  border-top-width: 0;
  padding-top: 0;
  padding-bottom: 0;
}
```

- Khi thu gọn: inner floor = `0 + 0 = 0` ⇒ track về đúng 0 ⇒ nhóm **đóng khít** (padding dọc và border biến mất cùng nhịp với `grid-template-rows` — không giật, không nhảy khung).
- `prefers-reduced-motion`: `.settings-group-inner` được thêm vào danh sách `transition: none !important` hiện có ⇒ tôn trọng cài đặt hệ thống.
- Không đổi HTML, không đổi JS, không đổi id/badge/khả năng thu gọn–mở rộng.

## Kiểm chứng

- **Cơ chế CSS**: suy từ quy tắc box-sizing/grid (border-box floor + contribution của scroll container) — khớp đúng phép đo ảnh chụp (~19–20px).
- **JS thu gọn**: không đổi — `scripts/smoke.mjs` (jsdom) vẫn kiểm tra toggle lớp `is-collapsed`, badge “N dòng”, `aria-expanded` — suite phải pass nguyên vẹn.
- **CHƯA nghiệm thu hình ảnh trực tiếp** trên WebView2 thật (sandbox không có binary WebView2 và không chạy được Chromium đầy đủ); cần bật/tắt từng nhóm trên bản v2.12.2 Windows để xác nhận “khít hoàn toàn”.

## Rủi ro & ghi chú

- Mở nhóm: padding trở lại `6/12` và border-top 1px — cùng hiệu ứng chuyển động như trước; không nhảy vì padding chuyển nhịp .22s đồng bộ với rows.
- Dark/light theme: không phụ thuộc theme (chỉ padding/border-width).
